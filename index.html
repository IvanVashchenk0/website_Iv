AHU Digitalization Pipeline

I developed an end-to-end AHU digitalization ecosystem that turns on-site iPhone video into final deliverables for Sales and Engineering. The pipeline converts field capture into scaled 3D point clouds and meshes via photogrammetry, then produces interactive 3D visualization, section-based CAD outputs with automated DXF cleanup/orthogonalization, and ML-driven component recognition (classification + YOLO detection).

  • Field capture: iPhone-based field video capture designed for reconstruction (consistent coverage, angles, and overlap to preserve usable geometry).
  • 3D reconstruction (photogrammetry): 3D model generation using the 3DF Zephyr SDK, with automated scale/orientation/cleanup enforced via control points so outputs are dimensionally consistent and downstream-ready.
  • 3D AHU App: Three.js interactive tool that visualizes the workflow and communicates before/after states of the digitalization pipeline on a real unit model.
  • Engineering sections: Extracted top/side 2D sections from the reconstructed model and used a C# DXF library to clean and orthogonalize the geometry into AutoCAD-ready deliverables.
  • Component recognition: Automated folder-level component classification plus a YOLO detection model to localize components (bounding boxes) for downstream automation and documentation.

Autonomous Sorting Machine

I designed and built an autonomous bearing sorting and packaging prototype. The system uses a Raspberry Pi vision pipeline with ML classification to identify components in real time, then synchronizes that output with mechanical actuation to route parts through a gravity-fed sorting path and into the correct packaging stream.

  • System architecture: End-to-end mechatronic workflow connecting part feed → vision capture → ML inference → actuation timing → sorted packaging output.
  • Mechanical feed + constraints: Gravity-fed hopper with custom sieves and 3D-printed guide components engineered to control orientation, spacing, and flow consistency for reliable sensing.
  • Vision + inference stack: Raspberry Pi–based camera pipeline running Teachable Machine classification for on-device identification with low latency.
  • Control + timing logic: Coordinated sensing, classification, and actuator triggers with timing windows to ensure each detected part is routed correctly without collisions or mis-sorts.
  • Integration + validation: Tuned mechanical tolerances and classification thresholds together to stabilize throughput and demonstrate repeatable, end-to-end automated sorting.

QuickScope

QuickScope is an internal automation tool I built to speed up project estimating and reduce repetitive manual work across Engineering and Sales. It pulls together the key project inputs, automates the Excel/reporting steps people used to do by hand, and keeps estimates consistent by propagating the same metadata across outputs and systems.

  • Workflow automation: Automated the core estimating flow so users can go from project inputs → standardized estimate outputs with fewer manual steps and fewer opportunities for mistakes.
  • C# + VBA execution: Implemented the main automation logic in C# with VBA/Excel integration to generate and populate estimate/report deliverables directly.
  • Salesforce integration: Integrated with Salesforce to connect estimates with project records and reduce duplicate data entry / mismatched metadata.
  • Location + context enrichment: Used the Google Maps API to automatically pull location-based context needed for the estimate workflow (instead of manual lookup).
  • Usability + speed: Built UI shortcuts and "one-click" style actions focused specifically on cutting cycle time and making the tool easy to use repeatedly.
